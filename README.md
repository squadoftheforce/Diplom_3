# Stellar Burgers - Автоматизированное тестирование веб-приложения

Проект содержит набор автоматизированных UI-тестов для веб-приложения Stellar Burgers с использованием Selenium WebDriver, JUnit4 и Allure для отчетов.

## Описание проекта

Тесты проверяют основные функциональные возможности приложения Stellar Burgers:
- Регистрация пользователей
- Авторизация пользователей через различные точки входа 
- Навигация в личном кабинете
- Конструктор бургеров и переключение между категориями ингредиентов

## Технологии

- Java 11
- Maven
- Selenium WebDriver 3.141.59
- JUnit 4.13.1
- Allure 2.23.0
- REST Assured 5.3.0
- WebDriverManager 4.4.3

## Реализованные тесты

### Регистрация пользователей
- Успешная регистрация и редирект на страницу входа
- Проверка возможности входа после регистрации
- Валидация пароля (минимум 6 символов)

### Вход в систему
- Вход по кнопке "Войти в аккаунт" на главной странице
- Вход через кнопку "Личный кабинет"
- Вход через форму регистрации
- Вход через форму восстановления пароля

### Личный кабинет
- Переход в личный кабинет
- Переход из личного кабинета в конструктор
- Переход из личного кабинета на главную страницу по логотипу
- Выход из аккаунта

### Конструктор бургера
- Переключение между категориями "Булки", "Соусы" и "Начинки"

## Запуск тестов

### Запуск в Chrome (по умолчанию)

```bash
mvn clean test
```

### Запуск в Яндекс.Браузере

```bash
mvn clean test -P yandex
```

### Генерация Allure-отчета

```bash
mvn allure:serve
```

## Особенности реализации

- Для каждой тестируемой страницы создан отдельный класс Page Object
- Тесты разделены по функциональности
- Для автоматизации тестов используется паттерн Page Object
- Используется Allure для создания подробных отчетов
- Тесты запускаются в Google Chrome и Яндекс.Браузере
- Для создания тестовых пользователей используется API
- Шаги тестов снабжены аннотациями @Step для Allure-отчета
